# Anti-Illegal Logging Device with LoRa and Edge Classification

## Project Overview

Welcome to the repository for our anti-illegal logging research project. Our initiative focuses on developing a robust device capable of detecting illegal logging activities through sound classification. Utilizing Long Range (LoRa) communication and edge computing, this device is designed to function in remote forest areas to identify and report illegal logging operations.

![Forest Overview](./img/illegal-logging.webp)

## Device Description

The anti-illegal logging device is a solar-powered unit that uses LoRa to transmit data and employs edge machine learning techniques to classify audio signals in real-time. By detecting the acoustic signature of chainsaws, the device can trigger alerts and facilitate immediate action against deforestation.

![Device Diagram](i./img/illegal-logging-device.webp)

## Key Features

- **Solar-Powered**: Functions continuously in remote areas without the need for conventional power sources.
- **LoRa Communication**: Enables long-range, low-power data transmission over vast distances, ideal for expansive forests.
- **Edge Classification**: Utilizes an on-device machine learning model to analyze and classify chainsaw sounds efficiently.

## Hardware Components

- Solar Panel Array
- Rechargeable Battery Pack
- LoRa-Enabled Microcontroller
- Audio Processing Module
